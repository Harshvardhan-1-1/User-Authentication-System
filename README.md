🔐 User Authentication System

A secure user authentication application built with Node.js, Express.js, MongoDB, Mongoose, JWT, and Bcrypt. The application allows users to register and log in securely with encrypted passwords and token-based authentication. User credentials are protected using password hashing, while JWT is used for session management. The project demonstrates backend authentication workflows, database integration, form handling, and secure user management practices.

✨ Features

* User Registration
* Secure Password Hashing with Bcrypt
* User Login Authentication
* JWT-based Token Generation
* Session Management using Cookies
* MongoDB Database Integration
* EJS Templating Engine
* Express.js Backend Routing

🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT (JSON Web Token)
* Bcrypt
* EJS
* HTML/CSS
